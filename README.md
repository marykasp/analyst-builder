# Analyst Builder

## Courses

### MySQL for Data Analytics

Full MySQL course covering querying, joins, subqueries, window functions,
data cleaning, and exploratory data analysis.

### Advanced MySQL for Data Analysis

Advanced concepts including CTEs and stored procedures.

### MySQL Interview Crash Course

Interview-focused SQL prep covering fundamentals tested in technical interviews.

### Tableau for Data Visualization

Tableau basics through advanced concepts with hands-on dashboard projects.
